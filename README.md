# Pork & Garlic Ice Cream Seasonal Planner

Local React and TypeScript decision-support tool for one rolling season. It uses browser storage only and does not contain the supplied Excel workbook.

## Run

`pnpm dev`

## Build

`pnpm build`

## Formula test

`node tests/financial.test.mjs`

Use **Load Team 3 Winter Example** to confirm the calculation validation: Net Profit -Sh 560 and Closing Cash Sh 74,940.
